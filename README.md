# Pairwise

Taste markets for creators on Monad.

Creators post two artworks. Fans predict which one the crowd will pick; a separate group votes blind.
Correct predictors earn the pool and onchain taste rep, the creator earns 5%, and every revealed voter
shares 2%.

Built for the Monad Metropolis hackathon (Social, Attention & Culture). Details land here as the
packages come together: `contracts/`, `indexer/`, `server/`, `web/`, with the frozen interface in `shared/`.
